# Fleeing Fright · 星光逃亡

一款以网格移动、星币收集与幽灵探测为核心的 Godot 3D 小游戏。

项目正在进行保守的体验优化，完成后的玩法说明、截图和验证记录会在本文件中更新。

## Internal docs

- [`_internal/architecture.md`](_internal/architecture.md)：运行结构与改动边界；代理在修改玩法前读取，结构变化后同步维护。
- [`_internal/progress.md`](_internal/progress.md)：按日期追加决策、检查结果和已知限制。

根目录 `AGENTS.md` 提供内部文档索引。
